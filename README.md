# CoachingOS Backend

Express + MongoDB backend for CoachingOS. It serves the API, manages admin PIN sessions, classes, students, attendance, fees, reports, backups, licensing, updates, and the public teacher QR scan endpoint.

The backend can also serve the built frontend from a `frontend/` directory for local installed deployments.

## Main Responsibilities

- Connect to MongoDB.
- Serve REST APIs under `/api`.
- Serve built frontend files in installed/local app mode.
- Authenticate admin pages with JWT.
- Enforce license checks.
- Generate and validate permanent student `attendanceToken` values.
- Mark public teacher QR attendance without teacher login.
- Use Pakistan date for attendance.
- Support local-network access from teacher mobiles.
- Run HTTPS on the local network for teacher camera support.

## Data Safety

Do not delete, reset, reseed, or recreate real user data.

Important rules:

- Existing students/classes/fees/attendance must remain in MongoDB.
- `tokens:backfill` only updates students where `attendanceToken` is missing.
- Existing `attendanceToken` values are never regenerated by the backfill script.
- Tokens are permanent because QR codes may be printed on student ID cards.
- Do not run seed scripts on an existing real database unless you intentionally want sample data.

### Variable Notes

- `MONGO_URI`: MongoDB connection string.
- `BACKEND_PORT` / `PORT`: backend listen port. `BACKEND_PORT` takes priority.
- `HOST`: use `0.0.0.0` for LAN access.
- `PUBLIC_HOST`: LAN IP or hostname shown in startup logs.
- `PUBLIC_DOMAIN`: optional domain. Leave empty for normal IP-based LAN mode.
- `FRONTEND_PORT`: Vite dev/preview port used for CORS startup hints.
- `CLIENT_ORIGIN`: comma-separated allowed origins.
- `ALLOW_LEGACY_ROLLNO_SCAN`: keep `false` for secure token QR flow.
- `COACHINGOS_LICENSE_DIR`: folder containing `license.json` and license state.

## Public Teacher QR Attendance

Teacher scan endpoint:

```http
POST /api/attendance/scan-public
```

Teachers do not log in. They open `/scan` on mobile and scan a token QR.

Expected request body:

```json
{
  "code": "{\"type\":\"coachingos_attendance\",\"token\":\"<student.attendanceToken>\"}"
}
```

Plain token is also accepted:

```json
{
  "token": "<student.attendanceToken>"
}
```

Backend behavior:

1. Validate token payload.
2. Find an active student by `attendanceToken`.
3. Use the student's saved `classId` and `className`.
4. Use Pakistan date from backend helper.
5. Create or update attendance day for that class/date.
6. Prevent duplicate attendance by returning `alreadyMarked: true`.
7. Save audit metadata:
   - `source`
   - `ip`
   - `userAgent`
   - `scannedAt`

Legacy roll number scan is disabled unless:

```env
ALLOW_LEGACY_ROLLNO_SCAN=true
```

Keep it `false` for new deployments.

## Attendance Token System

Each student has:

```js
attendanceToken: String
```

The token:

- Is generated automatically for new students.
- Is unique.
- Is stable/permanent.
- Is used for QR card printing.
- Does not regenerate on app restart, frontend render, rebuild, or student edit.

Backfill existing students:

```powershell
npm run tokens:backfill
```

The script only updates missing tokens:

```text
Students checked: <count>
Attendance tokens added: <count>
Students still missing attendanceToken: 0
```

Running it twice should add `0` tokens on the second run.

## Pakistan Date Handling

Attendance date source of truth is backend:

```text
src/utils/date.js
```

It uses `Asia/Karachi` and returns a `YYYY-MM-DD` date key.

Do not use `new Date().toISOString().slice(0, 10)` for attendance "today" because UTC can mark the wrong date in Pakistan around midnight.

## Troubleshooting

`MONGO_URI is required`:

- Ensure `.env` or `config.env` exists in backend working directory.
- Ensure it contains `MONGO_URI`.

MongoDB SRV lookup fails:

- Add `MONGO_ATLAS_HOSTS` and `MONGO_ATLAS_REPLICA_SET`.
- The backend can retry Atlas with direct hosts.

Teacher mobile camera is blocked:

- Confirm phone and PC are on the same WiFi/LAN.
- Confirm Windows Firewall allows port `5000`.
- If the page opens but camera is blocked, the browser requires trusted HTTPS for camera access. Use HTTPS URL first. If the certificate warning still prevents camera, trust the certificate on that device or use public SSL.

Public scan says student not found:

- Run `npm run tokens:backfill`.
- Reprint QR cards after token migration.
- Confirm student status is `Active`.
- Confirm `ALLOW_LEGACY_ROLLNO_SCAN=false` if testing new token flow.

Duplicate scan:

- This is normal. Backend returns `alreadyMarked: true` for the same student/date/class.

Port already in use:

```powershell
Get-NetTCPConnection -LocalPort 5000
```

Stop the process or change `BACKEND_PORT`.

License missing:

- Install a valid license using deployment scripts or license install script.
- Check `COACHINGOS_LICENSE_DIR`.
